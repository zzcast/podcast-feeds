# zzcast

Repo-specific agent notes. Machine-wide instructions live in `~/.agents/AGENTS.md`
and are already loaded; only add what is true of THIS repo.

- Every feed except `trudno-byt-bogom.xml` is generated by `update_feeds.py`. Never hand-edit a generated XML; change the script and re-run it.
- Feed artwork URLs carry the PNG's content hash, so a changed PNG must land in the same commit as the regenerated XML, or podcast apps cache the old image under the new URL.
- The repo is public: everything committed here is published.
